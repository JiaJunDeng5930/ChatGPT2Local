Setup

Core setup
1
ChatGPT account

Open ChatGPT in the embedded browser and sign in there. The desktop keeps its own persistent browser identity.

2
Checked runtime

Run the Bend-backed local service. Restarting it never resubmits an existing webpage operation.

3
Caller API

Use POST /v1/responses with an Idempotency-Key. Continue a conversation by passing its previous_response_id. Read the request schema at GET /v1/schema.

MCP

01

Enable full mode

Full mode exposes the two ChatGPT Web Tools tools. Browser-only keeps the webpage isolated from the caller tool executor.

02

Connect tunnel runtime

Enter the tunnel identity, then choose the runtime key file. Key contents never enter the UI or application configuration.

03

Use the connector

Keep the tunnel process running and enable the matching connector in ChatGPT. A disconnected transport does not cancel a task.
